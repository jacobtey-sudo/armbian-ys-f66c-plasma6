# Участие в проекте

## Коммиты

Формат сообщения:

```text
<область>: <краткое описание>
```

Области: `docs`, `overlay`, `scripts`, `config`, `plasma6`, `patches`.
Примеры:

```text
overlay: disable plasma-pa volume feedback
docs: describe the eMMC widget
config: bump board support to <commit>
```

Правила:

- один коммит — одно логическое изменение;
- обновление пина — отдельный коммит с причиной;
- в сообщении объяснять «почему», если изменение неочевидно.

## Перед коммитом

```sh
bash -n scripts/build.sh scripts/install-overlay.sh
shellcheck scripts/*.sh        # если установлен
```

Для изменений в overlay — проверить на устройстве или в свежем образе:

- вход через SDDM и загрузка Plasma;
- панель и апплеты;
- Maliit;
- звук и Bluetooth;
- `systemctl --failed`.

Для изменений в сборке — собрать образ и пройти smoke-тест из
[release.md](docs/release.md).

## Документация

- Документация на русском; команды и имена файлов — как в системе.
- Ссылки должны быть относительными внутри репозитория и работать.
- Версии и коммиты не дублируются в тексте — источник
  [`config/versions.env`](config/versions.env).
- Не добавлять даты внутренних проверок и отсылки к конкретным тестовым
  экземплярам: документ должен быть полезен любому владельцу платы.

## Чего не должно быть в git

- образы, `.deb`, архивы, дампы и логи;
- пароли, токены, SSH-ключи, приватные конфиги;
- реальные MAC-адреса, серийные номера, IP-адреса и hostname;
- абсолютные домашние пути конкретного пользователя.

MAC в `bluedevilglobalrc` — заглушки. UUID раздела eMMC в настройках виджета
документирован и относится к разметке носителя, а не к пользователю.

## Двоичные файлы

В overlay допустимы только небольшие собранные апплеты и плагины, для
которых в репозитории есть исходники/патч и инструкция по пересборке
([third-party.md](docs/third-party.md), [patches/README.md](patches/README.md)).
Новые бинарные файлы без источника не принимаются.

## Issues

В issue приложить:

- версию образа (`cat /etc/armbian-release`, `uname -r`);
- `plasmashell --version`;
- `systemctl --failed`;
- `journalctl -b -p err`;
- шаги воспроизведения.

Не прикладывать приватные данные, ключи и полные домашние каталоги.
