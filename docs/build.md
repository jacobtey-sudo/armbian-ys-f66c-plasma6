# Сборка

## Подход

Проект не форкает Armbian и не дублирует board support. Базовая сборка берётся
из `armbian-ys-f66c` на коммите из `config/versions.env`, а этот репозиторий
добавляет desktop-слой Plasma 6.

## Предварительные требования

- Linux x86_64 build host с зависимостями Armbian build framework;
- достаточно места для исходников, rootfs и образов;
- отдельная microSD для проверки, пока eMMC не станет основной системой;
- UART-доступ для bring-up, если образ не стартует.

## Порядок

1. Зафиксировать версии из `config/versions.env`.
2. Подготовить базовый Armbian build tree и board support на указанном коммите.
3. Наложить desktop-overlay и патчи из этого репозитория.
4. Собрать образ и записать его на **отдельную** microSD.
5. Проверить загрузку, панель, тач, звук, Wi-Fi/BT, камеру и Plasma.
6. Только после этого переносить систему на eMMC; microSD оставить как fallback.

> Точные команды сборки будут добавлены после переноса рабочего рецепта.
> До этого раздела считайте текущую систему источником истины.

## eMMC

Перед переносом:

- проверить, что U-Boot и загрузочные скрипты указывают на нужный rootfs;
- сохранить рабочую microSD;
- не форматировать eMMC, пока не сделан backup;
- файловая система rootfs: **ext4** (рекомендация для быстродействия).

## Артефакты

Образы, `.deb`, `.tar.*` и большие бинарники — в GitHub Releases, не в git.
Для каждого артефакта хранить SHA256 и версию из `config/versions.env`.
