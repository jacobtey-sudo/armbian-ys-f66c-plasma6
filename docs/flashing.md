# Запись образа и первый запуск

## Проверка образа

```sh
cd build/output/images
sha256sum -c *.img.sha
```

## Запись на microSD

**Внимание:** `/dev/sdX` — это именно карта, а не системный диск. Проверьте
`lsblk` перед записью.

```sh
sudo dd if=Armbian-*.img of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

Подойдут также balenaEtcher и Raspberry Pi Imager («Use custom image»).
После записи карта вставляется в планшет, питание подаётся через PoE.

## Первый запуск

1. Armbian выполняет штатный first-run: root-пароль, создание пользователя,
   Wi-Fi.
2. SDDM показывает экран входа в правильной ориентации.
3. После входа загружается Plasma 6 (Wayland) с настроенной панелью.

Образ не содержит предсозданного пользователя. Автологин в образе не
настроен; если после first-run он включён, уберите `User=` из
`/etc/sddm.conf.d/autologin.conf`.

## Быстрая проверка после первого запуска

- панель, Application Dashboard, Window Buttons, системные мониторы;
- поворот: консоль, SDDM и рабочий стол читаются в 1280×800;
- Maliit появляется в текстовых полях, переключается ru/en;
- звук: динамик, наушники (глушат динамик), микрофон;
- Wi-Fi и Ethernet, Bluetooth-наушники подключаются после перезагрузки;
- камера: `/dev/video10` отдаёт повёрнутую картинку;
- кнопка питания открывает меню завершения работы;
- `systemctl --failed` пуст.

## Установка на eMMC (опционально)

Проверенный сценарий — microSD. eMMC можно использовать как основной носитель:

```sh
sudo armbian-install
```

или неинтерактивно:

```sh
sudo armbian-install --target /dev/mmcblk0 --boot emmc --fs ext4 --yes
```

**Установка заменяет разметку eMMC.** Раздел данных eMMC будет потерян.
После установки выключите планшет, выньте microSD и включите снова.

## Питание и выключение

Питание — PoE, без батареи. Не выдёргивайте PoE без `shutdown`: уже были
случаи повреждения ext4 и перехода rootfs в read-only. После сбоя проверьте
файловую систему (`fsck`) и журнал.

## Консоль

UART2, **1500000 8N1**. В `bootenv` включён `earlycon`; лог загрузки виден
с первых строк. Подробности — в [troubleshooting.md](troubleshooting.md).
