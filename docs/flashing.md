# Запись образа и первый запуск

## Готовый образ из Releases

Скачайте в один каталог три файла из релиза: `.img.xz`,
`.img.xz.sha256` и `.img.txt`. Проверьте архив:

```sh
cd ~/Downloads
sha256sum -c *.img.xz.sha256
xz -t *.img.xz
```

`sha256sum` должен сказать `OK`, `xz -t` — завершиться без ошибок. Если
хэш не совпал, скачайте файл заново.

## Своя сборка

Если образ собран локально, проверяется несжатый `.img`:

```sh
cd build/output/images
sha256sum -c *.img.sha
```

## Запись на microSD

**Внимание:** `/dev/sdX` — это именно карта, а не системный диск. Проверьте
`lsblk` перед записью.

Используйте брендовую карту от 16 ГБ (Samsung EVO Select/Plus, SanDisk
Extreme/Ultra, Kingston Canvas Go! Plus). No-name карты могут молча портить
данные — симптомы и проверка в
[known-issues.md](known-issues.md#microsd-скорость-и-надёжность).

Готовый архив можно писать потоком, без распаковки на диск:

```sh
xz -dc Armbian-*.img.xz | sudo dd of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

Если используется несжатый `.img`:

```sh
sudo dd if=Armbian-*.img of=/dev/sdX bs=4M status=progress conv=fsync
sync
```

Подойдут также balenaEtcher и Raspberry Pi Imager («Use custom image»).
BalenaEtcher понимает `.img.xz` напрямую; если программа не открывает
архив, распакуйте его (`xz -dk *.img.xz`) и укажите `.img`.
После записи карта вставляется в планшет, питание подаётся через PoE.

## Первый запуск

1. Armbian выполняет штатный first-run: root-пароль, создание пользователя,
   Wi-Fi.
2. SDDM показывает экран входа в правильной ориентации.
3. После входа загружается Plasma 6 (Wayland) с настроенной панелью.

Образ не содержит предсозданного пользователя. Автологин в образе не
настроен; если после first-run он включён, уберите `User=` из
`/etc/sddm.conf.d/autologin.conf`.

## Проверка после прошивки

Скопируйте `scripts/smoke-test.sh` на планшет и запустите из терминала
Plasma (так доступны проверки звука и графической сессии):

```sh
./smoke-test.sh
```

Скрипт ничего не меняет. Он проверяет плату, ядро и DTB, носитель и
свободное место, failed units, поворот, звук, Bluetooth, камеру
`/dev/video10`, eMMC, thermal-зоны, governor CPU, сеть и сессию KWin.
Итог: `0` — ошибок нет, `1` — есть ошибки, `2` — предупреждения при
`--strict`.

Если запускаете через SSH или `sudo`, укажите пользователя сессии:

```sh
sudo ./smoke-test.sh --user <имя>
```

Ручная проверка дополняет скрипт:

- панель, Application Dashboard, Window Buttons, системные мониторы;
- поворот: консоль, SDDM и рабочий стол читаются в 1280×800;
- Maliit появляется в текстовых полях, переключается ru/en;
- звук: динамик, наушники (глушат динамик), микрофон;
- Wi-Fi и Ethernet, Bluetooth-наушники подключаются после перезагрузки;
- камера: `/dev/video10` отдаёт повёрнутую картинку;
- кнопка питания открывает меню завершения работы.

## Установка на eMMC (опционально)

Проверенный сценарий — microSD. eMMC можно использовать как основной носитель:

```sh
sudo armbian-install
```

или неинтерактивно:

```sh
sudo armbian-install --target /dev/mmcblk0 --boot emmc --fs ext4 --yes
```

**Установка заменяет разметку eMMC.** Раздел данных eMMC будет потерян.
После установки выключите планшет, выньте microSD и включите снова.
Если установка прервалась или система не загружается, порядок действий —
в [recovery.md](recovery.md).

## Питание и выключение

Питание — PoE, без батареи. Не выдёргивайте PoE без `shutdown`: уже были
случаи повреждения ext4 и перехода rootfs в read-only. После сбоя проверьте
файловую систему (`fsck`) и журнал.

## Консоль

UART2, **1500000 8N1**. В `bootenv` включён `earlycon`; лог загрузки виден
с первых строк. Распиновка J11 и восстановление — в
[recovery.md](recovery.md), диагностика — в
[troubleshooting.md](troubleshooting.md).
