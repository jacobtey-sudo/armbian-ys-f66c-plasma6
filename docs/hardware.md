# Железо

- **SoC:** Rockchip RK3566, 4×Cortex-A55.
- **GPU:** Mali-G52 2EE, драйвер Panfrost.
- **RAM:** 4 ГБ.
- **Дисплей:** DSI, 1280×800, поворот панели.
- **Накопители:** microSD и eMMC 28.9 ГБ (HS200).
- **Wi-Fi/BT:** две ревизии — AP6212 (brcmfmac) и AIC8800 (DKMS).
- **Bluetooth:** UART1, rfkill-bt.
- **Аудио:** RK817, выход на SPK.
- **Камера:** USB UVC.
- **Питание:** PoE, без основной батареи.

## Ограничения

- eMMC используется как основной носитель только после проверки образа на microSD.
- U-Boot может находиться на microSD; при переносе rootfs на eMMC это нужно учесть.
- Для отладки панели/загрузки нужен UART.
