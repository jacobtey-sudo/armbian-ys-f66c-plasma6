# Железо

| | |
| --- | --- |
| SoC | Rockchip RK3566, 4× Cortex-A55 |
| GPU | Mali-G52 2EE, драйвер Panfrost |
| RAM | 4 ГБ |
| Дисплей | 10.1", MIPI DSI, панель 800×1280, рабочий режим 1280×800 |
| Тачскрин | Goodix GT9271 (I2C1, INT GPIO3_C6 / RST GPIO3_C7) |
| Накопители | microSD и eMMC 28.9 ГБ (HS200) |
| Wi-Fi / BT | две ревизии: AP6212 (BCM43430A1) или AIC8800D80 (Wi-Fi 6) |
| Ethernet | IP101GR |
| PMIC / звук | RK809 с аудиокодеком RK817: динамик, 3.5 мм, микрофон |
| Камера | USB UVC за хабом, сенсор портретный |
| USB | USB host, OTG-порт в режиме host |
| Питание | PoE, без основной батареи |
| Кнопка питания | GPIO-кнопка → меню завершения работы KDE |
| Консоль | UART2, 1500000 8N1 |

## Ревизии Wi-Fi / Bluetooth

Платы выпускаются в двух вариантах; ревизия определяется по SDIO vendor:

- `02d0` — AP6212, Broadcom BCM43430A1 (`brcmfmac`, BT HCI 4.0);
- `c8a1` — AIC8800D80 (Wi-Fi 6, BT HCI 5.4, DKMS-драйвер).

Выбор DTB и прошивки Bluetooth выполняет board support; desktop-слой от
ревизии не зависит.

## Дисплей и поворот

Панель физически портретная. Поворот выполняется на трёх уровнях: fbcon
(`fbcon=rotate:1`), X11-гретер SDDM и KWin (`transform: Rotated270`).
Подробности — в [boot-rotation.md](boot-rotation.md).

## Накопители

- **microSD** — проверенный носитель для образа; ~16 МБ/с
  последовательного чтения.
- **eMMC** — 28.9 ГБ, HS200; заметно быстрее microSD. В текущей конфигурации
  раздел данных eMMC монтируется только для чтения в `/mnt/emmc` и
  отображается виджетом «Использование EMMC». Система может быть установлена
  на eMMC (см. [flashing.md](flashing.md)).

## Звук

- Динамик и разъём 3.5 мм; вставка наушников глушит динамик.
- Bluetooth: A2DP (SBC) для стерео, HFP (`headset-head-unit`) — моно для
  микрофона. SBC-XQ на этом чипе не работает и отключён.
- Громкость и устройства — стандартный Plasma PA; звук изменения громкости
  отключён, OSD остаётся.

## Камера

Внутренняя камера — USB UVC (не MIPI). Сенсор портретный, поэтому board
support поднимает виртуальную камеру `/dev/video10` с уже повёрнутой
картинкой. Приложения видят только её; сырое устройство остаётся root-only.

## Ограничения

- MIPI-камер (GC2145/OV5648) на плате нет.
- HDMI не входит в проверенный сценарий; основной вывод — встроенная панель.
- eMMC-раздел данных не изменяется; для установки системы на eMMC разметка
  заменяется целиком.
- UART нужен только для диагностики загрузки; в обычной работе не требуется.
