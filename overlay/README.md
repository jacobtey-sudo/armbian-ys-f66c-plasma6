# Overlay

Сюда переносятся только файлы конфигурации, которые должны попасть в образ:

- KWin (`kwinrc`) и параметры compositor;
- настройки Onboard/uinput;
- правила polkit для камеры;
- сервис speaker route;
- пользовательские `.desktop`-файлы;
- настройки локали и раскладки.

Не добавлять:

- пароли, токены, SSH-ключи;
- машинно-зависимые hostname и serial;
- большие бинарники.
